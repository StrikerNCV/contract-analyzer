# Como contribuir

1. Escolha uma história em `docs/specs/historias.md` e uma issue correspondente.
2. Crie branch: `docs/us-01-descricao`, `feat/us-01-descricao` ou `fix/us-01-descricao`.
3. Faça commits pequenos, execute `npm run check` e as verificações da alteração.
4. Abra PR com história, critérios atendidos, evidências de teste e pendências.
5. Outro integrante revisa e aprova. Integre apenas com CI verde.
6. Atualize o diário e crie a tag do checkpoint no commit revisado, quando a entrega estiver pronta.

O primeiro commit de bootstrap cria a base local; não substitui revisão do POD. Use a configuração em `docs/repositorio.md` antes das próximas mudanças na `main`.

Não adicionar licenças de terceiros nem publicar contratos reais. A licença do projeto será decidida pelo POD antes de distribuir o código a terceiros.
