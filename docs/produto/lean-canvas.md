# Lean Canvas — v1 (hipóteses)

| Bloco | Proposta inicial |
| --- | --- |
| Problema | Localizar obrigações, prazos e multas; consolidar informações espalhadas; preparar dúvidas para conferência |
| Segmentos | Responsáveis operacionais/administrativos de pequenas empresas prestadoras de serviços |
| Proposta única de valor | Uma primeira leitura do contrato, com cada ponto ligado à fonte para você conferir |
| Solução | PDF → resumo estruturado → obrigações/multas/atenção → trechos e páginas |
| Canais | Contatos do POD, comunidades de empreendedores e indicação; ainda não testados |
| Receita | Hipótese futura de assinatura por volume de documentos; sem preço, cobrança ou validação nesta fase |
| Custos | Inferência, hospedagem, processamento, suporte e revisão de qualidade; valores a medir |
| Métricas-chave | Tarefas corretas, tempo economizado, precisão/cobertura e fontes válidas |
| Vantagem difícil de copiar | Ainda não estabelecida. Corpus anotado e aprendizado de uso podem se tornar ativos; não são vantagem comprovada |

Alternativas presumidas: leitura manual, busca no PDF, planilha, chat genérico e assessoria. Hipótese de maior risco: a síntese rastreável resolver uma tarefa recorrente com valor suficiente para adoção. Discovery deve investigar isso antes de discutir preço.
